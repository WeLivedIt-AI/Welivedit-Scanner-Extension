# Re-hide after focus (v5.1.4)

When a hidden reply is shown or focused on X, the extension now provides two ways to hide it again:

1. A compact **Hide again** control directly on the revealed X reply.
2. A **Hide again on X** action in the extension card.

The control stays attached while the reply remains loaded in X. Re-hiding restores the hard-redaction cover and clears the manual reveal state.
